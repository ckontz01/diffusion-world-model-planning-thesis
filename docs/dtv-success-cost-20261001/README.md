- Primary DTV30-minus-ACID30 success/cost contrast; three fixed practical contrasts; all eight points; task-first and equal-task parent-clustered inference. Fixed checkpoints are not counted as independent sources. Small 1–3pp differences can remain unresolved at this sample size.
