## Physical interface

Horizon 5 grouped actions, 5 primitive actions per group, receding horizon 5 groups: 25 delivered actions per plan, at most two planning decisions and 50 delivered controller actions per episode. No H75/150-action ACV interface is imported. Each arm owns fresh physics, history, buffers, cost-call counter, solver generator and episode environment stream. Arm/budget labels are absent from proposal seeds. Identical method/input 28 and 30 cases share the first 28 solver populations in artificial tests. Different arms are not forced to keep later populations or trajectories equal after decisions differ.

PushT uses the accepted opt-in `pusht_fresh_initialization.py` instantaneous initializer. It builds fresh physics/goal render and sets state/velocity without the legacy setter's hidden integration step. No stale recorded start pixels replace fresh observations. The native endpoint is joint agent/block position norm <20 and wrapped block angle difference <pi/9, exactly the native callable. This is a prospective interface correction, not a reinterpretation of old absolute percentages.

Reacher uses native `qpos_match`, state qpos/qvel applied in reset before wrapper rendering, target qpos from the goal row, strict per-joint absolute difference <.05. The original action repeat of two internal dm_control steps remains native; 50 means delivered environment/controller actions, not physics integration substeps. Cube uses native single-cube state interface, qpos/qvel explicitly set before wrappers (the inherited reset consumes rather than forwards the state option), goal cube position/quaternion set before refreshed observation. Native success is cube position distance <=.04; quaternion is retained as target metadata, not added as a relaxed or stricter outcome criterion. Native internal integration rates are unchanged.

Initial native success is counted as success with zero actions/plans in every arm. Stop immediately at native success or legitimate termination/truncation; never step a terminal environment. Otherwise stop after 50 actions. Actual fresh visited observations drive replanning. Goals use the authenticated saved target frame; only allowlisted source/target numeric fields and target pixels are decoded. The new archive includes those input bytes. No new preprocessing fit is performed: recovered decoder statistics are applied with the historical two in-place float32 multiply/add operations; ImageNet processing and resize are retained. The world model consumes pixels and goal, not newly fitted state/proprio statistics.
