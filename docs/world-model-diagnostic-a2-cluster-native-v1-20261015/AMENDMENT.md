# A2 cluster-native route v1 — VM requirement removed

The human explicitly removed the VM requirement on 2026-10-15 and requested normal cluster execution. This is an execution/security amendment, not a new scientific configuration. It supersedes the facility-first VM requirement in C0 and the old cluster-recheck blocker; it does not rewrite those historical records.

The prospective route uses the existing cluster account, Slurm allocations and existing authenticated Apptainer/runtime environment. Loading whole Python checkpoint objects can execute their serialization code; SHA-256 authentication establishes which bytes are loaded, not that those bytes are harmless. An ordinary container is not claimed to provide the abandoned VM boundary. The source and artifacts must remain precisely bound, and loading is not performed on the Windows host or cluster login node.

Direct native loading of the fixed original objects is the candidate route. If used, it preserves parameters, buffers and plain tensor attributes rather than representing a state_dict-only reconstruction as equivalent. The V1 data-only validator remains a completed reusable component, but neither it nor the unexecuted VM conversion is represented as passed native parity. No real deserialization has occurred at the time of this amendment.

The fixed A2 protocol, 120 roots and seed/role manifest, two backbones/tasks, four cells, S1, bank/native-return reference, oracle separation, 50-action budget/tail and analysis remain unchanged. The prospective pinned DINOv2 encoder definition is retained; its training-time checkout remains unverified.

No checkpoint download, runtime-image build, modification of the existing scientific environment, new resource envelope, privileged host operation or historical-study change is authorized by this record. Existing PC VM/media are left untouched and remain included in preparation storage accounting. No monitor is resumed.

The existing package does not yet contain a real campaign runner: `wm_diag0_a2.path.NativeCampaign` deliberately refuses, and the documented native collectors/restoration/model bridges/scheduler acceptance are unfinished. Removing the VM requirement does not turn those artificial interfaces into implemented production code. The new route must verify and implement those concrete components before a research campaign is submitted. A technical runtime check must not be reported as experiment launch.

Original CPU/GPU cumulative and full-future reservations remain binding. The unused 1,800-second conversion reservation is retained, not silently reassigned. Any final native stage mapping must explicitly account for bypassed conversion/export operations without expanding total limits. This package initially performs only bounded source/runtime metadata checks and implementation; actual dispatch requires its own finite frozen contract and preservation.
