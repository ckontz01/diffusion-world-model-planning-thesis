Repository API reported no license; no license file was listed. Source inspected, not copied or executed. Author code uses general discrete-utility candidates, numerical beta search, finite-label calibration, propensity flooring and numerical ties. AV0 uses exact binary breakpoints, strictly validates known positive propensities, and returns uninformative sets when evidence is insufficient. This is not bitwise parity with that code.

Inspected `core/pfdr.py` (3,565 bytes): selective binomial risk tests and Bonferroni. AV0 retains the entire fixed family rather than dropping thresholds with fewer than 25 selections. Sparse thresholds simply cannot pass without sufficient evidence. No author dependencies installed.

## Local reference lineage, not scientific reuse

At base commit `d15d4aaf3e578b3ddc7f9bf236a8b69a7ed52075`, inspected `cluster/prometheus/acid_alternative/costs.py`: previous ACID residual is de-standardized into planner coordinates; time mean follows coordinate sum; per-population adaptive weight has an epsilon guard. Its noise is shared across candidate transitions and retained across solves. This earlier flow-IDM reconstruction is not official ACID. No historical code changed.

Inspected `acid_alternative/evaluate_matched.py`: `b0` receives no scorer, uses `SharedRolloutCostModel` plus `stable_worldmodel.CEMSolver`; defaults N=300/K=30/J=30, horizon/receding=5, action block=5, goal offset 25/budget 50. `independent_pusht_runtime.py` is **not** adopted wholesale: its SAGE and learned-proposer branches are unsuitable here. `lgp1_runtime.py` is also **not** instantiated: it loads a subgoal generator. Only documented initialization/decoder/termination interfaces are candidates for reuse.

AV0's `FrozenLatentCost` accepts supplied current/goal embeddings and frozen rollout/IDM callbacks. It computes final-goal distance directly, without local targets. Artificial tests exercise this port. It is not yet a tested image-to-action production connector. An admissible historical ACID checkpoint identity was not found in the inspected metadata; the future protocol treats that as a mandatory technical input blocker, not permission to use a weaker score or train silently.

No CPC, Pre-VLA, WCD, CheckVLA, LIBERO or new backbone is included; those remain possible later comparisons only.
