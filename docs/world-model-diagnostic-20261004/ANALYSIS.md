# Executable parent-paired analysis, no causal partition

wm_diag0.analysis.estimate consumes saved **already-sealed choices**, accepted candidate outcomes [parent,candidate,2 draws], native reference indices and optional separately recorded local progress. CLI requires --artificial and an artificial fixture; research execution remains disabled.

Within each of four settings report P0,P1,O0,O1 and the exact native-return reference. Average the two evaluation draws per parent; repeated deterministic outcomes are technical repetition, not extra n. Candidates, draws and paired backbones do not multiply independent parents. Use all32 diagnostic parents including initial successes, whose cells/reference must all be absorbed success.

Fixed contrasts: O0−P0; P1−P0; O1−O0; (O1−P1)−(O0−P0). Save every parent effect, gains/losses/ties, selected slot/identity changes, all cell/source summaries, candidate means and local progress. Binary full-budget native success is primary; truncation/terminal-failure/budget-failure reasons are retained in branch receipts and must accompany scientific reporting.

Uncertainty:10,000 paired parent bootstrap resamples, seed20261004, percentile95 intervals for each cell/contrast. Resample parents jointly across cells; do not pool backbone pairs as independent units. Intervals are descriptive, not multiplicity-controlled hypothesis tests or power guarantees. Cross-backbone contrasts, if later reported, must use the same paired parent resamples; no pooled raw-latent metric.

Hindsight: maximum of candidate two-draw means is explicitly **optimistic tested-bank opportunity**. Split-draw assessment selects the lowest-slot best on draw0 and evaluates on1, then reverses and averages. With deterministic identical repeats this does not remove optimism or add evidence; with two stochastic draws it remains noisy. Hindsight is neither deployable nor a fit/selection label for S1.

Separately report held-out realized readout coordinate MAE/RMSE; prediction MSE, rank diagnostics and local task distances retain their diagnostic status. No readout quality threshold is tuned against diagnostic outcomes. The component chain accepts all-fail, zero-effect and adverse oracle outcomes.

The operational effects can interact. Do not sum effects into percentages “caused by” prediction/scoring/search or infer one unique bottleneck. This discovery phase tests no practical predictor repair, full adaptive-search repair, repeated feedback or prospective repair recommendation. It may remain unresolved. No scientific outputs were generated during preparation; ARTIFICIAL-ANALYSIS-INPUT.json is an intentionally adverse test fixture, not research evidence.
