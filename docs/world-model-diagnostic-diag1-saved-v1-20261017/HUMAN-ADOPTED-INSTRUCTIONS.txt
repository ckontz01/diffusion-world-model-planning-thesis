5. DECOMPOSE THE ORIGINAL S0 ERROR AT THE DECISION HORIZON

Use the original terminal S0, not the unsuccessful S1 readout.

For each candidate, flatten only for algebra; retain the complete
native feature coordinates:

p = saved terminal predicted features
r = saved terminal realized features
g = saved own-backbone goal
e = p-r

Let gamma be:
1 for Le-WM's terminal squared-error SUM;
1/D for DINO's terminal squared-error MEAN over D coordinates.

Then the squared-distance identity is:

gamma*||p-g||² - gamma*||r-g||²
  = 2*gamma*<r-g,e> + gamma*||e||².

Compute the signed goal-direction term and squared-error term.
Verify the identity using float64 analysis arithmetic.

Keep native stored-dtype scoring and authoritative saved selections
separate from this higher-precision algebra. Record round-off residuals;
do not change historical costs or choices because float64 differs near
a tie.

For i=P0 and j=O0, decompose:

(predicted_cost_j - predicted_cost_i)
 - (realized_cost_j - realized_cost_i).

This identifies the error in the RELATIVE ordering that changed the
decision. Absolute prediction error alone is not that quantity.

Report how the two terms contribute to the ordering difference.
Do not call a large latent MSE proof of a harmful decision error.

Use the complete parent population, with gains/losses/ties as descriptive
strata. Do not analyze only the ten favorable Reacher parents.

Reuse already published time-position MSE summaries where useful.
