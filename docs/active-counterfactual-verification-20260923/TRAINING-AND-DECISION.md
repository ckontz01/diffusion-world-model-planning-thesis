# Frozen implementation recipe (before neural fitting)

Only the existing local NumPy runtime is used. Explicit reverse-mode derivatives are implemented and finite-difference checked; there is no dependency installation. All inputs are deployable vectors, not source, split, case, mode or slot IDs. Identifiers are confined to grouping and receipts.

## Feature and parameter contract

For latent dimension D, the pre-prefix history consists of three observed latents (left-repeat initially), fixed goal latent, ten actual prior two-coordinate primitives (zero-filled initially), and six clock/budget constants. Append the proposed five-action prefix and its frozen predicted latent: x has 5D+36 coordinates. Each candidate has ten actions plus its frozen terminal prediction: a has D+20. Residual r is the actual observed prefix latent minus the frozen prediction (D coordinates). The ordinary model additionally receives the actual post-prefix latent and r explicitly; both are recoverable from the same x and r used by the mixture. No privileged physics or future labels are features.

Mixture: x → 32 tanh shared context; a linear head produces 4 logits, 4D means, 4D variances and 3 terminal-status logits. Candidate [context,a] → 32 tanh → 4 sigmoid outcome probabilities. Variance is .01 + 3.99 sigmoid(raw) in fitting-only standardized coordinates. Posterior uses log mixture probabilities plus the full diagonal-Gaussian log density, with log-sum-exp normalization. The response head never receives the suffix bank.

Artificial D=4: x=56, a=24, **5,067** trainable mixture parameters. Ordinary MLP [x,a,post,r] → 64 tanh → 64 tanh → sigmoid: **9,921** parameters. Proposed real D=192: x=996, a=212; mixture **90,795**, ordinary **106,177** parameters. No contrast compression or dimension selection is performed.

One source record contains its prefix records. A prefix record has exactly one response, status and up to four unique associated suffix labels. Terminal prefixes have no response or physically unused suffix labels. Masks are not used to multiply a terminal observation into fictitious outcome samples. The response NLL is counted once per actual canonical active prefix, divided by D. BCE is computed on the posterior-mixture Bernoulli probability, averaged over unique suffixes. Terminal categorical cross-entropy is counted once per prefix. Sum these three weight-1 terms; average prefixes within source, then sources. Thus coupled branches never become independent source evidence. Preprocessing is fit from fitting records only and stored with provenance; no validation/test statistics are used.

Fixed Adam: learning rate .001, betas (.9,.999), epsilon 1e-8, no decay, global gradient norm cap 5. Twelve epochs, source batches 64, shuffle seed 94013; final checkpoint only. Mixture init 94011; ordinary init 94012. For each unchanged prototype case, use its original 1,024 fitting sources with seed 24000: 192 updates/model/case. No hyperparameter, seed, threshold, scenario or training-size sweep. Separate generated validation/test sources (128/256, seeds 94101/94102) are whole-source grouped and used only for reporting. Their exact distributions are the original seven cases; reversal is retained. This one fixed neural wiring run is not the supplied 30-seed table run and not a claim of sample efficiency.

The seven cases' original discrete responses are embedded as [-1,+1] in one of four residual coordinates, with zeros elsewhere. Physical abstract action codes are embedded in five/ten action vectors. This is an interface encoding of the same abstract laws, not manufactured PushT physics or a new favorable efficacy scenario. Terminal/mock contract cases are separate wiring tests, not additions to efficacy tables.

## Unconditional value and information matching

For each prefix, predict terminal-success S, terminal-failure F, active A probabilities. The active response distribution is the four-component Gaussian mixture. V = P(S) + P(A) E_r[max_i q_i | A]; failure contributes zero. Committing to the baseline is P(S_0)+P(A_0) sum_m pi_m s_m(baseline suffix). Terminal-prefix consequences and action consumption are part of the full-budget outcome, not a second arbitrary probe penalty.

Fixed integration: 16 independent standard normals and their antithetics per mixture component (32/component, 128 total), weighted by pi/32. Seed 94021 is independent of proposal, training and physical streams; the same standard normals are shared across prefixes/active comparators. No adaptive sample count. Original baseline commitment wins exact ties; other ties use exact action-content hashes. Expected native success, not residual size or entropy, drives selection.

A static commits before observing. B uses the unchanged baseline prefix and feedback. C maximizes V against original baseline commitment. D performs and charges all of C's integration, keeps its chosen prefix, but fixes the suffix to its unconditional mean before execution. E uses a larger ordinary predictor with exactly the same observations/actions/predictions/residual, shared sampler and terminal model. F uses exact Bayesian contingency on the tractable original artificial law; the real feasible adaptation is Bayesian last-layer regression on E's frozen features, unit Gaussian noise/prior, source-balanced fitting and a clipped mean. This approximation is explicitly not exact for binary robotics outcomes and is not a full ALPaCA reproduction. It receives the same response samples and budget; no source-count fiction.

Early vanilla-CEM replanning is a separate practical arm: keep the original prefix, then build an unrestricted new fifteen-action plan from the actual five-action observation; replan every fifteen primitives thereafter, stopping at original action 150. It is not a fixed-tree selector. It receives the complete N300/K30/J30 solve, not a weakened shortlist. Search is charged independently. No mechanism claim is supported until a reviewed real pilot beats both same-information feedback and this ordinary early-replanning arm.
