# CVL-1 final development result — 15 September 2026

Decision, verbatim: **`stop_no_ranking_promise`**. Technical validity and training
support passed. The fixed ranking-promise conjunction failed because the MLP
ensemble's selected-candidate success difference versus continuation was negative.
No closed-loop evaluation, replacement model, further collection or automatic
follow-up is authorized by this result. Historical decisions remain unchanged.

## Frozen test and denominators

The unchanged [protocol](PROTOCOL.md), sections 1–5, defines a sampled-eight
candidate test, two distinct candidate-coupled continuation streams, and native
success through the original remaining budget. Entire references are disjoint
between training, ranking validation and the unused closed-loop role. This is
outcome-informed development on already-exposed indices 0–1599, not confirmation.
The three neural seeds 8201/8202/8203 form one fixed probability ensemble; no
seed or checkpoint was selected using validation results.

## Interpretation and boundary

This compact evaluator learned some pairwise ordering signal but did not improve
the frozen argmax selected-candidate outcome on the declared subset. Pairwise
discrimination and useful top-choice selection are different requirements.
The result does not identify why the top-choice rule underperformed, prove that
value learning cannot work, or establish that immediate ranking is generally
inferior. It supplies no closed-loop efficacy estimate: all 32 closed-loop source
references remained unused by this CVL run, and all 512 conditional episodes were
not run. Continuation remains the unchanged baseline. No mixture tuning, model
redesign, new proposal or confirmation access follows automatically.
